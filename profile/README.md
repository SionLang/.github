# Sion

A programming language built for AI agents to write, verify and ship software.

- Few tokens, one way to do each thing
- Memory safe with no lifetime syntax, no null
- Effects declared in signatures (`uses fs`, `uses net`)
- Compiler errors as JSON with machine-applicable fixes
- Bootstraps from a throwaway seed, then compiles itself

Start at [sion-spec](https://github.com/SionLang/sion-spec). Tests live in [sion-tests](https://github.com/SionLang/sion-tests).
